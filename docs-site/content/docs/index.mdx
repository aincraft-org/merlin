# Merlin Paper

The current reference for Merlin Paper: enchantments, magical authoring systems, ritual crafting, runtime behavior, and configuration.

## What is implemented

- **81 registered altar definitions:** 6 vanilla or over-cap definitions and 75 custom definitions.
- A custom **Eterna and Quanta Enchanter's Altar Matrix** opened from an enchanting table.
- Marked Scribe books with a bounded natural-language spell DSL.
- Glyph maps, elemental ink, glyph tomes, classification, and casting.
- Ritual Anchors and Pedestals that produce marked crafting intermediates.
- A modular custom-enchantment dispatcher covering combat, tools, armor, movement, fishing, buckets, projectiles, and passive effects.
